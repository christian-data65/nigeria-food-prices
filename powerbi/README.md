# Nigeria Food Price Analysis – Power BI Dashboard

## Project Overview
This dashboard analyzes food prices across different states in Nigeria using historical food price data.

## Objectives
- Compare food prices across Nigerian states.
- Identify food items with the highest and lowest average prices.
- Analyze changes in food prices over time.
- Identify states with relatively high and low food prices.


## Tools Used
- Microsoft Power BI
- Power Query
- DAX
